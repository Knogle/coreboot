Established facts from this capture:

- raw byte 0 is `0x93`: CRC coverage bytes `0..116`, 256 bytes total, and
  256 bytes used;
- SPD revision is `1.3` and memory type is DDR3 (`0x0b`);
- the base CRC calculated by B06H and stored in bytes 126/127 is `0xec4f`;
- all 128 byte-data reads completed, each with seven observed status polls;
- total polls were `0x380`, maximum and last-command polls were seven;
- initial, enabled, before-command, and after-command pin samples were `0x07`;
- final `HSTSTAT=0x42` reflects the retained software semaphore plus successful
  completion before the already-audited release write.

Bytes `0x80..0xff` were not read by B06H and remain unknown at this milestone.
