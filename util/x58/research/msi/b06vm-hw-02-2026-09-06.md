The first execution stopped safely in the CAR recovery monitor because CMOS
still contained the persistent auto-reset guard from an earlier image. The
guard was explicitly cleared (`0xec -> 0x2c`) and the next execution followed
the complete B06VL-derived producer path.

## Proven path

The retained trace shows both complete 8-MiB destructive test windows passing,
valid CBMEM below 24 MiB, the B06VM full-low-memory MTRR transition, real
postcar, and real ramstage. Ramstage accepted the exact version-9 handoff and
entered the new selective PCI path.

The following downstream distinction is decisive:

```text
PCI: 00:00:03.0 [8086/340a] enabled
PCI: 00:00:03.0 scanning...
PCI: pci_scan_bus for segment group 00 bus 01
PCI: Static device PCI: 00:01:00.0 not found, disabling it.

PCI: 00:00:1c.4 scanning...
PCI: pci_scan_bus for segment group 00 bus 02
PCI: 00:02:00.0 [10ec/8168] enabled

[RAMSTAGE] B06VM bridge child escaped allowlist
```

The terminal POST code was `0x38`. SeaBIOS did not start in this run.

This is not an NVIDIA-versus-AMD identity failure. An answering endpoint with
an unexpected identity would have reached B06VM's identity gate and stopped at
POST `0x39`. Instead, configuration reads behind X58 root port `00:03.0`
returned no device, while the ICH10R downstream RTL8168 answered normally.

## Next isolated hypothesis

Intel documents that an X58 IOH strapped for `Wait_on_BIOS` holds PCI Express
link training until firmware selects a port layout and sets the one-shot Start
Bifurcation bit. MSI documents the X58 Pro-E slot layout as two x16 links and
one x4 link. The next image therefore tests only IOU0 / root port `00:03.0`:

```text
ECAM 00:03.0 + 0x190 = 0x000c  # x16 mode plus Start Bifurcation
poll 00:03.0 + 0x0a2 bit 13    # Data Link Layer Link Active, bounded timeout
```

The physical HD 5450 ROM is sufficient once the card becomes visible. No AMD
VBIOS is to be embedded in CBFS; SeaBIOS should map the card's ROM BAR and run
the matching legacy image. A missing GPU remains a serial-only payload
fallback in the successor rather than another topology halt.

- Intel X58 Express Chipset Datasheet, sections 5.1.2 and 17.12.5.21:

- MSI X58 Pro-E specifications (`2x16, 1x4`):
